# Trip Genie ✈

個人旅遊行程規劃平台。單檔 HTML，前端 vanilla JS。

## 功能
- 首頁行程卡片牆（新增/編輯/刪除行程）
- 每日時間軸（9 時間段，早/午/晚餐底色帶）
- 行程格 CRUD、跨日/跨段拖曳、跨時間段長卡
- 編輯／閱覽模式、行程詳情
- Checklist（整趟一份，6 類）
- 三色系視覺（森林／海洋／城市）

## 技術
- Phase 1：localStorage 暫存（本機）
- Phase 2：GitHub Pages 主機 + Firebase（Google 登入 + Firestore 雲端同步 + 允許清單權限）
- Phase 3：Google 地圖詳情頁、匯出 HTML/PDF/手機版
